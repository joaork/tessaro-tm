# Referências do desafio

O **Regulamento Oficial do Hackathon Auto-T&M Karsten**, quatro páginas, rege o escopo, a avaliação e a entrega. A cópia local fica em `docs/referencias/regulamento_hackathon_karsten_oficial.pdf`. O encerramento consta no regulamento para **11/11/2026, às 14h**, no horário local do evento.

O regulamento aponta para a pasta do Kit de Apoio. Os arquivos usados no projeto foram obtidos dessa pasta em 10/11/2026. O acesso e o compartilhamento seguem as condições da organização. [Pasta do Kit de Apoio do Desafio](https://drive.google.com/drive/folders/1Cufkkll0jnr135UQmd7J9kRjrHPdgVRw).

| Arquivo local em `kit-oficial/` | Papel |
| --- | --- |
| `Entradas.ods` | Bases de apoio nas abas `MATRIZ_DE_ELEMENTOS` e `TEMPO-CM` |
| `demanda_000.txt` | Entrada da operação oficial `PO-SL-001`, revisão `00` |
| `PO-SL-000.ods` | Modelo preenchido para conferência do cabeçalho e das linhas da PO |

Guarde os originais no diretório local indicado e mantenha as planilhas intactas. As regras do Git excluem os arquivos oficiais. Uma distribuição pública do regulamento ou do kit depende de autorização da organização. Avaliadores com acesso autorizado podem colocá-los nessa pasta e reproduzir o teste. Para experimentar a interface sem o kit, carregue a base demonstrativa identificada no [README](../../README.md).
